# Tugas 2 - Website Development

## Deskripsi

Proyek ini merupakan tugas pembelajaran PPLG berupa pembuatan website menggunakan HTML dan CSS.

## Tujuan

* Memahami struktur dasar HTML.
* Mempelajari penggunaan CSS untuk mengatur tampilan website.
* Mengembangkan keterampilan dasar dalam pembuatan website.

## Teknologi yang Digunakan

* HTML
* CSS
* GitHub

## Struktur File

* `index.html` — berisi struktur dan konten halaman website.
* `style.css` — berisi kode CSS untuk mengatur tampilan website.

## Kesimpulan

Melalui proyek ini, saya belajar membuat halaman website dan mengatur tampilannya menggunakan HTML dan CSS.
